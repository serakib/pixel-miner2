# Pixel Miner — C++ / WebAssembly

A responsive browser mining game built with C++17 and Emscripten.

## Features

- Camera-follow mining world
- Endless depth progression
- Copper and crystal resources
- Energy pickups
- HP and energy systems
- Cave crawler enemies
- Hazards
- Score + persistent best score
- Keyboard, mouse and touch controls
- Pause / resume
- Restart
- Responsive HUD
- Built-in How to Play guide
- GitHub Pages deployment

## Controls

- WASD / Arrow Keys — move
- Click an adjacent tile — move/mine
- Mobile — on-screen D-pad
- Space / P — pause

## Goal

Explore the cave, collect resources, survive enemies and reach the green exit to descend deeper.
